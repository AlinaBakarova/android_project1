# Проверки

Проверено 9 октября 2026 года.

## Автоматические

Сборка debug APK, генерация ViewBinding и компиляция графа Dagger 2 проходят.

- `core-common`: 6 тестов — offset, конец/пустая страница, переполнение, поиск/дубликаты, пустые сообщения.
- `core-network`: 10 MockWebServer-тестов — OAuth, URL/query, кириллица, история всех страниц, создание, отправка, malformed JSON, обязательные поля, HTTP 400/401/403/404/429/500 и отсутствие автоматического повтора POST, включая обрыв соединения.
- `feature-chats`: 2 теста PagingSource — переход страниц, удаление дубликатов, LoadResult.Error и повторная загрузка.
- `feature-messages`: 3 теста ViewModel — двойная отправка, успех, сохранение черновика и данных при ошибке, запрет пустого сообщения.

Итого: 21 модульный тест, без ошибок и пропусков.

Дополнительно прошёл один Espresso-тест на эмуляторе API 26: открытие диалога создания, запрет пустого и пробельного имени, включение кнопки для непустого имени, отмена без POST. Найденное падение из-за неправильных LayoutParams исправлено XML-разметкой с ViewBinding. Перед отменой тест закрывает системную клавиатуру; первая попытка не могла отправить нажатие в перекрытую клавиатурой область.

## Реальный API

HTTPS и заголовок oauth подтверждены. GET чатов, GET истории без пагинации и с пагинацией проверены. Для чата 1 запрос без пагинации вернул все 136 сообщений на момент проверки; явная пагинация сообщает тот же total.

Создан проверочный чат `Messenger validation 2026-10-09` (id 101). Отправлено одно сообщение. Сервер подтвердил форматы обеих POST-операций. При первой попытке отправки сервер ответил 429; дополнительный GET подтвердил отсутствие сообщения, затем отдельная проверка отправки успешно завершилась. Нагрузочное тестирование не проводилось.

## Повторяемость

Из отдельной копии финальных исходников без `.git`, `build/`, `.gradle/` и `local.properties` выполнены сборка APK, Lint и все 21 тест: 207 задач выполнены заново, ошибок и пропусков нет. SDK задавался через ANDROID_HOME, токен — через MESSENGER_OAUTH_TOKEN; исходники не исправлялись.

Повторный запуск установочного скрипта также успешно завершил сборку и проверки.

## Интерфейс

Проверено на AOSP API 26 x86_64 в программном режиме без KVM:

- Чаты загружаются через реальный HTTPS API, локальные аватары отображаются через Glide.
- Поиск `Works` показывает один загруженный чат `WorksOnMyMachine`.
- Выбор чата открывает реальные сообщения.
- Portrait → landscape: отображаются оба фрагмента, выбранный чат, поиск и черновик `rotation-draft` сохраняются.
- Landscape → portrait: выбранный чат и черновик сохраняются.
- Кнопка в панели возвращает к чатам с сохранённым поиском; аппаратный Back сначала закрывает открытую клавиатуру.
- Фоновый процесс приложения остановлен через run-as; смена PID подтверждена. После запуска восстановлены выбранный чат и черновик, а после возврата к чатам — поисковая строка.
- Подпись debug APK проверена apksigner (v2).
- Android Lint проходит без ошибок, с шестью предупреждениями: разные ID контейнеров для ориентаций, отсутствие отдельной иконки / правил извлечения данных и дополнительный корневой FrameLayout.

Скриншоты: [чаты](docs/screenshots/portrait-chats.png), [сообщения](docs/screenshots/portrait-messages.png), [landscape](docs/screenshots/landscape.png).

## Ограничения проверки

На физическом устройстве и Android API 35 приложение ещё не проверялось. Программный эмулятор API 35 не завершил холодную загрузку за наблюдавшийся интервал. API 26 загрузился; первые запуск и установка медленные, системный интерфейс эмулятора показывал ANR. Проверки не подтверждают производительность на реальном устройстве.

Не все ручные сочетания сетевых ошибок, большого шрифта и длинных сообщений пройдены на устройстве; сетевые ошибки проверены автоматическими тестами. Реальный сервер иногда отвечает 429. Автоматических повторов POST нет.

GitHub-репозиторий изначально пуст. Восстановление опубликованной среды в новой задаче не проверялось.
